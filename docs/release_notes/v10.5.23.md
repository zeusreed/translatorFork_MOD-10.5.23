# translatorFork_MOD v10.5.23

## Улучшения

- Большие файлы виртуальной файловой системы теперь автоматически переносятся из RAM во временное дисковое хранилище. Для хранилища действует общий лимит, а копирование EPUB выполняется потоком без чтения всей книги в память.
- Промежуточные ZIP-архивы при очистке EPUB используют временное дисковое хранилище после достижения порога размера, а результат копируется обратно потоком.
- Зависимости для runtime, разработки и сборки зафиксированы в lock-файлах с SHA-256-хэшами. CI и скрипты сборки проверяют хэши при установке.
- Windows launcher выбирает Python 3.11/3.10, пересоздаёт окружение с несовместимой версией Python и устанавливает runtime-зависимости по хэшированному lock-файлу.
